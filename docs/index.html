🎁 Tặng Shard cho petertukogay

Bot chạy trên GitHub nên nút tặng nằm trên trang Actions của repo — bạn chỉ cần bấm 1 lần:

1. Mở Run workflowNút bên dưới sẽ dẫn thẳng tới trang đó
2. Chọn mode = giftvà nhập số lượng shard muốn tặng
3. Bấm Run workflowBot vào game, gửi `/shard pay`, log xác nhận rồi tự thoát
⚠️ Nhập số lượng rồi bấm nút — trang GitHub sẽ mở ra, bạn dán số đó vào ô amount (hoặc để trống = gửi hết). Nhớ petertukogay phải đang online.
